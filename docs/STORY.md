# Story V1.1 交接

2026-10-26。本轮在原 Story 组件、辅助函数与局部样式上压缩篇幅，保留 Archivo / CJK、白底、近黑与 `#1646e8`，以及纸张、轨道、草稿三个图形母题。没有新增依赖或重建视觉系统；纸色与宋体仍仅用于 Story。

## 内容与三幕结构

`src/data/story.ts` 是文案唯一来源，采用用户本轮确认的精简第三人称文案，23 个内容字符串按原文保留，后续排版不得静默改写。原中文展示标题保留，副标题为 `An unfinished story.`。

1. **开场**：三行错位标题、简短人物介绍与一句主引言，以星形图案延续原页面语气。
2. **慢与快并置**：Quiet 暖纸与 Restless 蓝底共用一个阅读区域；桌面左右对照，移动端上下排列。纸张「慢」字与轨道缩为局部图形。
3. **继续做东西**：草稿里的反复修改连接未来愿望、蓝色结尾「故事才刚写了几页。」与签名，不再拆出独立未来／感谢章节。

正文桌面为 **17px**，760px 以下为 **16px**，通过收紧结构和留白缩短页面。五章目录、独立 Offline 章节、照片位及照片数据接口均已移除；当前不保留补图任务，也没有新增 Fun 内容。阅读箭头链接 `#sides`，原生锚点支持刷新定位。

## 动效与无障碍

纸张和轨道保持静态，仅草稿保留一次 **750ms** WAAPI 转正动效，由 `IntersectionObserver` 首次进入时触发，不循环、不隐藏文字。初始减少动态偏好不启动动画；运行中切换会取消，卸载也会取消并断开观察。CSS 同时关闭 Story 过渡。语义标题、可见焦点及既有站点跳过导航链接保留。

## 变更与本地命令

本轮仅修改四个文件：`src/data/story.ts`、`src/sections/StoryPage.tsx`、`src/styles/story.css`、`docs/STORY.md`。App、导航、Hero、Work、Fun、全局样式与依赖均无本轮修改；其他既有用户改动不属于此次精修。

在项目根目录执行：

```sh
pnpm run build
node scripts/deploy/check-dist.mjs
pnpm run dev --host 127.0.0.1 --port 5176
```

当前本地预览：`http://127.0.0.1:5176/story`。构建及静态检查应使用一致的 `PORTFOLIO_BASE`、`PORTFOLIO_ORIGIN` 配置。

## 本轮验证与边界

本地构建通过，静态产物检查通过 **8 个入口**（包含既有 Fun）；既有 15 项使用 mock 的 AskHy 测试通过。浏览器证据与截图位于 `.impeccable/review/story-v1.1/`，以 `checks.json`、`before.json`、`regression.json`、`production.json` 为检查记录：

- 320、390、768、1000、1280、1440、1920px 七种宽度均无横向溢出；23 个内容字符串无缺失，恰有三个顶层幕，旧目录／独立章节／照片节点为 0，未记录运行错误。
- Story 导航激活，阅读链接及刷新定位通过；减少动态偏好使活动动画从 **1 降至 0**。
- 构建产物的 `/story`、`/story/`、`/story/#making` 均显示三幕，Story／Fun／Work 导航通过，返回 Work 位于导航下方 100px；Story 没有资源或运行失败。静态验证环境没有后端，访问既有 Fun 时的 `/api/ask-hy/health` 缺失为已知限制。
- 首页与 Work 排除导航后的前后像素一致。
